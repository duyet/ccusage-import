summa (Latin: sum, total) is a small Rust CLI. It reads Claude Code, Codex, OpenCode, Cursor, Grok, and other agent logs, then writes one table: ccusage_events.

Machines keep Cursor and Grok on. Sinks dedup. This host is the cloud hub: clients send a token, the worker stamps the tenant, and usage lands in ClickHouse and MotherDuck. D1 stores keys only.

Daily, session, block, project rows. Model breakdowns exploded. ReplacingMergeTree + DuckDB key delete.

summa cronjob install. launchd, systemd --user, or crontab. Job runs update then import.
